# AgriDrishti - Advanced Predictive Tools for Farmers and Market Stability

#### Team Name - CODE4CHANGE
#### Project Focus - Predictive Analytics for Agriculture


## A Brief Overview of the Platform:
Interact and explore our predictive tools here - [AgriDrishti Website]([https://agridrishti.com/](https://agridrishti.netlify.app/))

AgriDrishti is an advanced data analytics platform designed to assist farmers, traders, and market regulators in making informed decisions about crop production, market trends, and price volatility. Our platform leverages state-of-the-art machine learning models to provide accurate market predictions, ensuring profitability and stability in the agricultural sector.

*Key Features Include:*  

- **Price Volatility Predictor:** Uses ARIMA and LSTM models to forecast sudden price changes in key crops, helping stakeholders make strategic decisions on storage and sale timing.  
- **Regional Price Impact Estimator:** Analyzes region-specific factors such as landholding size, climate, and soil type to provide tailored market intelligence.  
- **Market Trend Analysis:** Offers data-driven insights into past price trends, supply data, and market interventions for better strategic planning.  
- **User-Centric Approach:** Farmers, traders, and government agencies can access real-time analytics and reports for better market intervention strategies.  

Our platform aims to build a data-driven agricultural ecosystem that ensures profitability, minimizes risks, and promotes sustainable farming practices.

## Code Execution Instructions:

### How to Run the AgriDrishti Web Application

#### 1. Clone the Repository  
Open your terminal and run the following command:  
```bash  
git clone https://github.com/YourUsername/agridrishti.git  
cd agridrishti  
```
This will download the project and move you into its directory.

#### 2. Install Dependencies  
Once in the project directory, install the required dependencies using npm:
```bash  
npm install  
```
This command installs all the necessary packages for the application to run.

#### 3. Start the Application  
After the dependencies are installed, start the development server with the following command:
```bash  
npm run dev  
```
This will start the local development server, allowing you to interact with the application in your browser.

#### 4. Access the Application  
Open your web browser and navigate to `http://localhost:3000` to view and interact with AgriDrishti.
